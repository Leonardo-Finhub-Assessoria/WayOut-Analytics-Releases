# WayOut Analytics para Windows

Aplicativo local de consulta ao WayOut ERP. Os dados e a senha SQL permanecem na maquina/rede do cliente.

## Instalar

Baixe o arquivo `WayOut-Analytics-Setup-VERSAO-x64.exe` na [versao mais recente](https://github.com/Leonardo-Finhub-Assessoria/WayOut-Analytics-Releases/releases/latest) e siga o assistente. Windows 10/11 de 64 bits. Nao e necessario instalar Node.js. Abra o atalho WayOut Analytics e configure a conexao de leitura do seu proprio ERP.

## Atualizar

O aplicativo avisa quando uma versao nova estiver disponivel. Voce tambem pode usar **Ajuda > Verificar atualizacoes**. Confirme o download e escolha quando instalar e reiniciar. As configuracoes permanecem salvas; a senha SQL deve ser informada novamente apos reiniciar. Sem internet, o programa continua funcionando localmente.

Este repositorio publica somente instaladores e metadados de atualizacao. O codigo-fonte e privado. Nao envie dados, senhas ou relatorios do ERP aqui.

O instalador inicial nao possui certificado digital do editor; o Windows pode exibir aviso de editor desconhecido.
